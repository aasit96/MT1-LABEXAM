Shopping Cart Management System

Welcome! This page is served by the native Node.js HTTP server using the FS module.

Project Description

A simple shopping cart application built to demonstrate the Node.js HTTP module, the FS module, routing, Express.js and REST API CRUD operations. Data is stored in JavaScript arrays (no database).

Features

Native HTTP server with routing
HTML file served using fs.readFile()
Express.js REST API
Full CRUD operations
JSON request and response handling
Validation and error handling

Servers

Native HTTP Server
Port: 3000
Express REST API
Port: 4000

Native HTTP Server Endpoints (Port 3000)

Method Endpoint Description
GET / Welcome page
GET /cart All cart products (JSON)
GET /about About the application
GET /home This HTML page
POST /add-to-cart Add a product to the cart

Express REST API Endpoints (Port 4000)

Method Endpoint Description
GET /cart Get all products
GET /cart/:id Get one product by ID
POST /cart Add a new product
PUT /cart/:id Update a product
DELETE /cart/:id Delete a product
